# CustomDiscs v2 — свои пластинки ПОД КЛЮЧ (Minecraft 26.2, Paper)

Кидаешь песни в папку → перезапускаешь сервер → всё. Плагин **сам**:
конвертирует аудио, рисует текстуру диска, собирает текстурпак (даже
поверх KSEPSP) и регистрирует песни в проигрывателе — **без датапаков**.

## Установка

1. `CustomDiscs.jar` → `plugins/` (Paper 26.2, Java 25+)
2. *(необязательно)* свой текстурпак (например KSEPSP) → `plugins/CustomDiscs/` —
   плагин найдёт его сам и вольёт свои ресурсы в него
3. Запусти сервер.

## Как добавить песню (весь процесс)

```
1. Кинь файл (mp3, ogg, wav, flac, m4a) в  plugins/CustomDiscs/songs/
2. Перезапусти сервер  ИЛИ  напиши /disc import
3. Готово: /disc list  покажет новую пластинку,  /disc give <id>  выдаст её
```

Название файла = название пластинки (кириллица работает, id создастся сам).
Плагин сам: ffmpeg-конвертация в моно-ogg (нет ffmpeg в системе — попробует
скачать сам в `bin/`; готовые .ogg принимает и без него), уникальная текстура
(каждой песне — свой цвет диска), модель, кейсы во все `music_disc_*.json`,
`sounds.json`, запись в config.yml, регистрация песни в реестре jukebox,
пересборка `plugins/CustomDiscs/SmakcraftMusic.zip` (+ файл `.sha1`).

**Единственный ручной шаг** — после добавления новых песен перезапусти сервер
(реестр песен заполняется при старте — так работает Minecraft).

## Раздача текстурпака игрокам

Плагин собирает `plugins/CustomDiscs/SmakcraftMusic.zip` при каждом старте.
Положи его на хостинг/CDN и укажи в `server.properties`:

```properties
resource-pack=<ссылка на SmakcraftMusic.zip>
resource-pack-sha1=<содержимое SmakcraftMusic.zip.sha1>
resource-pack-required=true
```

Если `resourcepack-source` пуст, а в папке плагина лежит ровно один zip —
плагин сам возьмёт его за основу (клиентам хватит ОДНОГО пака: и KSEPSP,
и твои пластинки).

## Команды (`/disc`, алиасы `/plastinka`, `/mdisc`; право `customdiscs.admin`)

| Команда | Что делает |
|---|---|
| `/disc import` | импортировать всё из `plugins/CustomDiscs/songs/` |
| `/disc pack` | пересобрать текстурпак прямо сейчас |
| `/disc list` | список пластинок |
| `/disc give <id> [ник] [кол-во]` | выдать пластинку |
| `/disc giveall <id> [кол-во]` | выдать всем онлайн |
| `/disc add <id> <диск> <Название>` | добавить пластинку без песни |
| `/disc remove <id>` | удалить пластинку |
| `/disc play <id> [ник]` | включить песню игроку |
| `/disc stop [ник]` | остановить звук пластинок (и jukebox) |
| `/disc debug <id>` | диагностика: песня в реестре? |
| `/disc reload` | перечитать config.yml |

## config.yml (всё необязательно)

```yaml
auto-import: true          # импорт папки songs/ при старте
auto-rebuild-pack: true    # пересборка SmakcraftMusic.zip при старте
auto-material: MUSIC_DISC_13
resourcepack-source: ""    # zip-исходник для слияния (или положи zip в папку — найдётся сам)
ffmpeg-path: ""            # пусто = PATH → bin/ → автоскачивание
```

Раздел `discs` ведётся автоматически; править можно (см. комментарии в файле).
`display_name` — без `&`-кодов (это триггер текстуры), лор можно красить.

## Как это устроено

- **Bootstrap-фаза Paper**: при старте сервера плагин регистрирует все песни
  из `jukebox-songs.list` прямо в динамический реестр `jukebox_song`
  (Paper Registry API) — поэтому датапак не нужен.
- **Компонент `jukebox_playable`**: на выдаваемых дисках — ссылка на песню;
  ванильный проигрыватель играет её как родную (радиус ~64 блока, компаратор 15).
- **Текстура по имени**: `minecraft:select` по `custom_name` в
  `assets/minecraft/items/music_disc_*.json` — как в KSEPSP.
- **Авто-лечение**: диск, выданный до импорта песни, само-чинится при первой
  вставке в проигрыватель.

## Сборка из исходников

JDK 25+, затем: `./gradlew build` → `build/libs/CustomDiscs.jar`.

Проверено на Paper 26.2 build 121: первый старт (импорт + сборка пака),
второй старт (регистрация песен), `/disc debug`, слияние с KSEPSP,
восстановление пака из кэша — всё зелёное.
