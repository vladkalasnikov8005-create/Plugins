# KSEPSP — каталог переименований и моделей (9.5.1 → 9.6.2)

Разбор двух архивов ресурспака **KSEPSP** (`KSEPSP-9-5-1.zip`, `KSEPSP-9-6-2.zip`) и сайт-каталог:
все переименования предметов, превью каждой модели (2D-картинка + интерактивный 3D), сравнение версий.

## Что внутри

```
ksepsp-catalog/
├── tools/
│   ├── pack_lib.py      # парсер пака: items/*.json -> переименования, брони (RPT), статистика
│   ├── render_lib.py    # софтверный рендер Minecraft-моделей (numpy + Pillow)
│   └── build_site.py    # сборка: распаковка -> парсинг -> diff -> рендер -> JSON + geom-шарды
├── serve.py             # статический сервер (по умолчанию порт 8123)
├── build/               # распакованные паки (в git не попадает, создаётся автоматически)
└── site/                # сам сайт
    ├── index.html, styles.css, app.js, viewer3d.js, favicon.svg
    ├── vendor/          # three.js (MIT), локально
    └── data/            # сгенерированные данные: meta/items/diff/armor, img/, tex/, geom/, armor/
```

## Запуск

```bash
python3 tools/build_site.py --workers 2      # полная сборка (распаковка + рендер всех превью)
python3 serve.py 8123                        # http://localhost:8123/
```

Полезные флаги: `--skip-render` (не перерисовывать превью, если они уже есть), `--skip-geom` (без 3D-геометрии).

Зависимости: Python 3 + `pillow`, `numpy` (`pip install --break-system-packages pillow numpy`).

## Как устроен пак (что мы разобрали)

| Путь в паке | Что это |
|---|---|
| `assets/minecraft/items/*.json` | переименования предметов: `minecraft:select` по `minecraft:custom_name` → `minecraft:model` |
| вложенные `minecraft:range_dispatch` / `minecraft:condition` / `minecraft:select(display_context)` | состояния модели: натянутый лук/арбалет, вид от 1-го лица, иконка в инвентаре |
| `assets/ksepsp/models/item/9_0/**` | актуальные модели: оружие, инструменты, шапки, еда, мебель, зелья |
| `assets/ksepsp/models/item/8_0/**` | легаси-модели предыдущей эпохи пака (257 переименований в 9.5.1, 222 в 9.6.2) |
| `assets/minecraft/rpt/swappers/**` | **новое в 9.6.2**: замена текстуры брони по имени (мод RPF/RPT, не ванильный механизм) — 222 названия, 94 набора текстур |
| `assets/minecraft/optifine/**` | OptiFine CIT/CEM: эмиссивы, модели котов, лодок, armor stand, снеговика и т. д. |

## Что даёт сайт

* **Каталог** — 2522 переименования (9.6.2) / 2413 (9.5.1) с превью, поиском (рус/англ), фильтрами
  (категория, базовый предмет, «новые», «изменённые», «другое написание», «перекрашиваемые», «состояния», «легаси 8.0», «битые текстуры»)
  и выгрузкой списка в TXT/CSV.
* **Карточка** — что за предмет базово, что писать в наковальне, все состояния модели, используемые текстуры,
  путь модели в паке и путь файла-переопределения.
* **3D-просмотр** — three.js, геометрия квадов (как в паке), неоновые переключатели вида, покраска красителем для перекрашиваемых моделей.
* **Сравнение** — что добавилось (117), изменилось (38), изменило написание (2), пропало (8), новая броня (222), статистика по файлам.
* **Модели** — таблица всех моделей пака с превью, названиями и текстурами.
* **Файлы** — побайтовое сравнение содержимого архивов по группам.

## Точность

Превью отрисовывается собственным рендером (орбитальная проекция, затенение по сторонам света как в Minecraft,
UV-развёртка из модели). Для моделей без `elements` (плоские спрайты `item/generated`) рисуется текстура `layer0`.
Если в паке нет файла текстуры (например, легаси-текстуры 8.0, которых нет в 9.6.2) — используется
чёрно-розовая заглушка, а карточка помечается «битая текстура» (таких переименований 3).

Данные собраны только из самих архивов: ни одного числа «на глаз».
